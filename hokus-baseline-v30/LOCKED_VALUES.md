# Kilitli değerler (Hıdır Yüksel'in panelde elle belirlediği ölçüler)

Bu değerler **src/config/defaults.json** içinde de durur ve `src/js/app.js` varsayılanlarıyla aynıdır.
Değiştirmek için ilgili kişiyle konuşulur; PR / birleştirmede bu dosya ve `defaults.json` birlikte güncellenir.

| Panel | Anahtar | Değer |
|---|---|---|
| Menü (üst sağ) · Sağdan ek boşluk | `nv.r` | -2.15 cqw |
| Footer · Yan boşluk — mikro ayar | `ft.mo` | 23 px |
| SEARCH · Dikey konum (kaydır) | `i.search.dy` | -0.8 cqw |
| INSTAGRAM · Dikey konum (kaydır) | `i.ig.dy` | -0.6 cqw |
| VIMEO · Dikey konum (kaydır) | `i.vimeo.dy` | -0.6 cqw |
| GIPHY · Dikey konum (kaydır) | `i.giphy.dy` | -0.6 cqw |
| Works sayfası · Yan boşluk (sol / sağ) | `wk.mx` | 4 cqw |
| Hover · Toplam süre | `rf.dur` | 0.3 s |
| Hover · Hepsinin karışık kaldığı ilk bölüm | `rf.lead` | 0.12 s |
| Hover · Harf değişim hızı | `rf.cps` | 12 /sn |
| Hover · Oturma sırası rastgeleliği | `rf.rnd` | 1 |
| Hover · Mouse çıkarken de oynat | `fx.leave` | kapalı |

Ayrıca v30'un **tüm** varsayılanları (yerleşim, Moods ikon konumları, toggle vb.) onaylı kabul edilir:
tam liste `docs/settings-reference.json` (otomatik üretilmiş referans).
